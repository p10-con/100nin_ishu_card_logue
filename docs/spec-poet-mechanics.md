# 詠み人・憑依・カスタム俳句 機能仕様

## 概要

百人一首カードローグの拡張システム。歌人（Poet）をゲームプレイの能動的な要素として機能させる。

---

## 1. 詠み人要素

### 1.1 詠み人フィールド

バトル画面に新たな専用スロット「**詠み人フィールド**」を設置する。

- スロット数：1〜3（プロフィール強化で拡張可能）
- 歌人カードをここに配置することで、持続的な効果を得る
- フィールドに置かれた歌人は「保持状態」となる

### 1.2 歌人の取得方法

歌人はカードとは別の「**歌人カード**」として入手する。

| 入手経路 | 内容 |
|---------|------|
| ドラフト報酬 | バトル勝利後のドラフトで稀に出現 |
| ショップ | 金（エネルギー的なリソース）で購入 |
| イベント | ランダムイベントの選択肢 |
| ボス撃破 | 特定ボス（例：天智天皇、後鳥羽院）から入手 |

### 1.3 歌人の使用モード

歌人には2つの使用方法がある。

#### (A) 即時使用
- 手札から直接プレイ（通常カードと同様）
- **その場限りの強力な一発効果**を発動して墓地へ送られる
- 例：「在原業平」即時使用 → 次に使うカードの哀情・優雅を2倍にする

#### (B) 詠み人フィールドへ配置（保持）
- 手札から詠み人フィールドへ移動させる
- **持続的なパッシブ効果**を発揮する（バトル終了まで、もしくは条件が解除されるまで）
- 例：「紀貫之」保持 → 自分のターン開始時に elegance +2

### 1.4 詠み人フィールドの効果分類

| 効果タイプ | 説明 | 例 |
|-----------|------|-----|
| ターン開始時 | 毎ターン効果が発動 | HP回復、ステータス上昇 |
| カード使用時 | 特定条件のカードを使うたびに発動 | 同じテーマのカード使用でボーナス |
| シナジー強化 | デッキのシナジーボーナスを増幅 | 六歌仙フィールドで attack +10% |
| バフ付与 | プレイヤーに状態異常（良い効果）を付与 | 防御カードの効果+5 |
| 歌枕効果 | 場（フィールド全体）の属性を変化させる | 秋テーマの歌人で autumn カードの attack × 1.3 |

### 1.5 歌人の属性と効果傾向

歌人のフラグを活かした効果設計の指針：

| フラグ | 効果の傾向 |
|-------|----------|
| `rank: 'legendary'` | 強力だが発動条件が厳しい |
| `isRokkkasen: true` | 六歌仙シナジー：六歌仙が2人以上フィールドにいると追加効果 |
| `isSanjurokkkasen: true` | 三十六歌仙シナジー：デッキの cohesion に補正 |
| `hasExile: true` | 流罪歌人：リスク型効果（強いが被ダメが増えるなど） |
| `hasTonsure: true` | 出家歌人：防御・回復系の効果に特化 |
| `gender: 'female'` | love / lament テーマ強化傾向 |

## 2. 憑依システム

### 2.1 概要

**憑依**は、詠み人フィールドの「保持」よりも強力な状態。プレイヤー自身が歌人に乗っ取られ、その歌人としてバトルを行う。

### 2.2 憑依の発生条件（案）

以下のいずれかを満たすと憑依状態に移行する。

| 条件 | 内容 |
|------|------|
| 連続詠唱 | 同じ歌人の句を3ターン連続で使用 |
| 感情爆発 | pathos または elegance が閾値（80以上）に達した状態で特定カードを使用 |
| 歌人の意志 | 特定の歌人カードを即時使用した際、確率で憑依が発生 |
| イベント発火 | 特定のランイベントの選択肢（「歌人に身を委ねる」など） |
| HP低下 | HP が maxHp の 20% 以下になった状態で出家歌人がフィールドにいる |

### 2.3 憑依中の状態

- プレイヤーのアバター・名前が歌人名に変化（UIフレーバー）
- 詠み人フィールドの効果が**憑依ボーナス**に差し替わり、より強力な効果が発動する
- 歌人固有の**デバフ**が同時に課される

### 2.4 憑依効果の設計例

| 歌人 | 憑依ボーナス | 憑依デバフ |
|------|------------|----------|
| 小野小町 | love / lament カードの attack × 2.5、使用後に相手を「魅了」状態にする | 毎ターン HP -3（美の代償） |
| 西行法師 | 全カードのコスト -1、defense が無効になり全力攻撃になる | defense 値が 0 にリセット |
| 在原業平 | 手札をすべて捨て、7枚引き直す。引いたカードすべての attack +15 | 引いたカードは次のターン使えない（詠嘆の遅延） |
| 後鳥羽院 | 相手の defense を無視してダメージを与える | バトル終了後 HP を 1 に固定（流罪の厳しさ） |
| 藤原定家 | 手札の中から最も elegance の高いカードを自動発動 × 3 | その 3 枚は次のバトルで使用不能 |

### 2.5 憑依の解除

- ターン数経過（歌人ごとに異なる持続ターン数。例：3〜5ターン）
- 特定のカードまたはアイテムを使用（「正気の払い」的な解除カード）
- HPが閾値以下になったとき（強制解除）

### 2.6 憑依レベル（拡張案）

繰り返し同じ歌人に憑依されると「親密度」が上がり、次回憑依時のデバフが軽減される。

| 親密度 | 状態 | デバフ強度 |
|-------|------|----------|
| 0 | 初回 | 100% |
| 1〜2 | 慣れ | 75% |
| 3〜4 | 信頼 | 50% |
| 5+ | 一体化 | 25%（実質なし） |

## 3. カスタム俳句（エンドコンテンツ）

### 3.1 概要

ゲームを一定回数クリア後に解放される特殊なカード生成システム。

### 3.2 候補A：自由詠み

プレイヤーが自分で**新しい和歌を自由入力**し、AIがその句の能力値を判定してカード化する。

#### フロー

```
1. プレイヤーが和歌（上の句 + 下の句）を日本語で入力
2. Claude API に送信
3. AI が以下を判定：
   - テーマ（Theme）：spring / summer / autumn / winter / love / lament / travel / nature / misc
   - 修辞技法（RhetoricalDevice）：枕詞 / 掛け言葉 / 縁語 / 本歌取り / 序詞 / 体言止め
   - イメージワード（imagery）
   - 感情強度（emotionIntensity）：0〜100
   - 能力値推定：attack / defense / elegance / pathos
4. 生成されたカードをデッキに追加可能
```

#### AI判定プロンプト方針

- 詠んだときのゲーム内状況（バトル中か、HP残量、使用済みカードなど）も判定に加味する
- 例：ピンチ状態で「山高く…」という力強い句 → attack が高めになる
- ゲームバランス上限：attack 上限 70、defense 上限 60（既存カードの最大値に準拠）
- 品質が低い句（意味不明・文字数不足など）はAIが「佳作」として弱めに判定

#### 保存と制限

- 1ラン中に詠めるカスタム句：最大3首
- デッキに組み込めるカスタム句：最大5枚
- カスタム句は `isCustom: true` フラグを持つ特殊カード

---

### 3.3 候補B：句の合体（合句）

2枚の百人一首カードを合体させて**1枚の「合句」カード**を生成する。

#### フロー

```
1. デッキまたは手持ちから2枚のカードを選択
2. 合体確認画面で「上の句」「下の句」をどちらから取るか選択
3. 合句カードが生成される：
   - 上の句：選択した方のカードの上の句
   - 下の句：もう一方のカードの下の句
   - ステータス：2枚の平均（一部加算）
   - テーマ：2枚のテーマの和集合
   - 修辞技法：2枚のデバイスの和集合
```

#### ステータス計算

```
合句.attack  = (A.attack  + B.attack)  / 2 + シナジーボーナス
合句.defense = (A.defense + B.defense) / 2 + シナジーボーナス
合句.elegance = max(A.elegance, B.elegance)
合句.pathos   = max(A.pathos,   B.pathos)
合句.energy   = Math.ceil((A.energy + B.energy) / 2)
```

#### シナジーボーナス

| 条件 | ボーナス |
|------|--------|
| 2枚が同じテーマ | attack +10, defense +10 |
| 2枚が同じ歌人 | elegance +15, pathos +15 |
| 六歌仙 × 六歌仙 | 全ステータス × 1.2 |
| 恋 × 哀愁テーマ | pathos +20 |
| 天皇 rank × 天皇 rank | attack +20 |

#### 再合体

- 合句同士をさらに合体させる「**重句（かさねく）**」も可能
- 重句のコスト（energy）は +1 増加
- 重句は最大2回まで（3枚分の元カードから生まれた句）

#### 制限

- 元のカード2枚はデッキから失われる（消費型）
- 1ランで合体できる回数：最大5回
- 合句カードには `isFused: true` フラグと `sourceCards: [cardId, cardId]` を持つ

## 4. 既存型への影響

### 4.1 `RunState` への追加フィールド（案）

```typescript
// 詠み人フィールド
poetField: PoetCard[];           // 現在フィールドに配置された歌人
possessionState: PossessionState | null; // 憑依中の状態

// 歌人手持ち
poetHand: PoetCard[];
```

### 4.2 新規型（案）

```typescript
// 歌人カード
interface PoetCard {
  id: string;
  poet: Poet;
  instantEffect: PoetEffect;     // 即時使用効果
  passiveEffect: PoetEffect;     // フィールド保持効果
  possessionEffect: PoetEffect;  // 憑依時ボーナス効果
  possessionDebuff: PoetDebuff;  // 憑依デバフ
  possessionDuration: number;   // 憑依持続ターン数
}

// 憑依状態
interface PossessionState {
  poet: Poet;
  turnsRemaining: number;
  activeBonus: PoetEffect;
  activeDebuff: PoetDebuff;
}

// カスタムカード拡張
interface Card {
  // ... 既存フィールド
  isCustom?: boolean;    // 候補A：自由詠み
  isFused?: boolean;     // 候補B：合句
  sourceCards?: string[]; // 合体元のカードID
}
```

## 5. 優先度と実装順序（案）

| フェーズ | 内容 | 優先度 |
|---------|------|--------|
| Phase 1 | 詠み人フィールド基本機能（保持・パッシブ効果） | 高 |
| Phase 2 | 歌人の即時使用 | 高 |
| Phase 3 | 憑依システム（発生条件・基本エフェクト） | 中 |
| Phase 4 | 憑依親密度 | 低 |
| Phase 5 | カスタム俳句（候補AまたはB） | 低（エンドコンテンツ） |
