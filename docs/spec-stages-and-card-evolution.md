# 地名ステージ・カード進化システム 機能仕様

## 概要

2つの独立した拡張を定義する。

1. **歌枕ステージ**：ダンジョンを百人一首の歌枕（地名）に置き換え、関連する句・歌人にシナジーを与える
2. **カード進化システム**：Balatro的な「カードそのものが変容し続ける」体験を百人一首に移植する

---

## 1. 歌枕ステージ

### 1.1 設計思想

現在の抽象的なダンジョン名（花の道、嵐の旅路…）を、百人一首に実際に詠まれた**歌枕（実在の地名）**に置き換える。
その地に縁のある句・歌人がデッキにあると**地縁シナジー**が発動し、プレイスタイルが変わる。

### 1.3 地縁シナジーの仕組み

バトル開始時、デッキ内のカードを走査し**地縁カード**を判定する。

```
地縁カード = (カードの poemNumber が縁の句リストに含まれる)
          OR (カードの poet.id が縁の歌人リストに含まれる)
          OR (カードの themes が地域のテーマと一致する)
```

#### シナジーレベル

| 地縁カード数 | シナジーレベル | ボーナス |
|------------|-------------|--------|
| 1〜2枚 | 縁あり | 地縁カードの全ステータス × 1.1 |
| 3〜4枚 | 深い縁 | × 1.25 + ステージ固有効果Lv1 |
| 5枚以上 | 歌枕一色 | × 1.5 + ステージ固有効果Lv2 + 特殊演出 |

### 1.4 地縁シナジーの具体例

#### 因幡ステージ
- 縁: No.16、旅テーマ全般
- Lv1効果：旅テーマのカードのコスト（energy）-1
- Lv2効果：旅テーマ連続使用でスタック damage ボーナス

#### 吉野ステージ
- 縁: No.31（坂上是則「朝ぼらけ有明の月…」）、No.94（参議雅経）、冬テーマ
- Lv1効果：冬テーマ attack × 1.3
- Lv2効果：冬テーマ使用時に「雪が積もる」スタック付与 → 一定数でバースト（敵に大ダメージ）

#### 大江山ステージ
- 縁: No.60 小式部内侍
- ギミック「遠距離ペナルティ」：小式部の句がデッキにないと毎ターン attack -5（母の援護なし）
  - 逆に No.60 をデッキに入れていると attack +15（母の知恵）

## 2. カード進化システム（Balatro的）

### 2.1 設計思想

Balatro の面白さの核心は「**ランを通じてカードが変容し、想定外のコンボが生まれていく**」ことにある。

本ゲームに移植する際のキーコンセプト：
- **句は詠まれるほど深みを増す**（usedCount はすでに存在する）
- **詠み慣れた句に筆跡が重なる**（Enhancement）
- **場に残る歌の記憶が積み重なる**（Joker的なタイル）
- **修辞技法の習熟が爆発する**（Multiplier）

### 2.2 システム構成（4層）

```
カードそのもの
  └─ [1] 詠み上げレベル（usedCountで自動成長）
  └─ [2] 筆の跡（Enhancement：1枚のカードに付与）
  └─ [3] 封印（Seal：発動条件付きの特殊効果）

場全体
  └─ [4] 歌枕タイル（Utamakura Tile：Joker相当、ラン全体に影響）
```

---

### 2.3 [1] 詠み上げレベル

既存の `usedCount` を活かす。使い込んだカードは自動で育つ。

| usedCount | レベル | 変化 |
|-----------|-------|------|
| 0〜2 | Lv0 | 基本値 |
| 3〜6 | Lv1 | attack +3, defense +2 |
| 7〜11 | Lv2 | attack +6, defense +4、カードのビジュアルに「使い込み」表示 |
| 12〜 | Lv3 | attack +10, defense +6、カード名に「◎」付与 |

ランをまたいでも保持される（プロフィールに保存）ことで「愛用の一首」が育つ愛着が生まれる。

> Balatro の「よく使うカードほど強くなる」感覚に対応。

---

### 2.4 [2] 筆の跡（Enhancement）

カードに1つだけ付与できる**永続的な変質**。
ランダムイベント、ショップ、特定の歌人カード即時使用で入手できる「御霊アイテム」を消費して付与する。

| 名称 | 効果 | フレーバー |
|------|------|----------|
| 金泥（きんでい） | elegance × 1.5 | 金の箔で装飾された高貴な一首 |
| 朱（しゅ） | attack × 1.3 / elegance -10 | 情熱の赤が激情を呼ぶ |
| 墨流し（すみながし） | 使用するたびにランダムでテーマが変化 | 水に墨を流したような揺らぎ |
| 薄紙（うすがみ） | energy -1（コスト軽減）| 軽い紙に書かれた即興の句 |
| 蘇芳（すおう） | 同じターンに2枚目以降として使うと attack × 2 | 重ねて染めるほど深みが出る |
| 焦げ（こげ） | HP が半分以下のとき attack × 1.8 | 追い詰められて輝く命の句 |
| 宿り木（やどりぎ） | 山札に戻るとき次のドローコストが -1 | 宿りながら根を張る |

1枚のカードに付与できる筆の跡は**1種類のみ**。上書きは可能（前の跡は消える）。

---

### 2.5 [3] 封印（Seal）

カードに1つだけ付与できる**発動条件付き特殊効果**。
御霊アイテムとは別の「封符」アイテムで付与する。

| 名称 | 発動条件 | 効果 |
|------|---------|------|
| 春封印（はるふういん） | このカードを使用した後 | 手札から春テーマのカードを1枚引く |
| 恋封印（こいふういん） | このカードを使用した後 | 次に使うカードのコスト 0 |
| 月封印（つきふういん） | 3ターン目以降に使用 | attack × 2 |
| 旅封印（たびふういん） | 旅テーマのカードの直後に使用 | 山札からランダムに1枚手札に加える |
| 哀封印（あいふういん） | HPが最大値の50%以下のとき | pathos +20、使用後に1HP回復 |
| 鬼封印（おにふういん） | 使用した句が敵を倒したとき | 次のバトルに持ち越してこのカードの attack +5（永続スタック） |

封印は**同じカードに筆の跡と両立可能**（筆の跡 + 封印 = 最大2つの変質）。

---

### 2.6 [4] 歌枕タイル（Utamakura Tile）

**Balatro の「ジョーカー」に相当**する、ラン中ずっと場に置かれる効果タイル。
最大5枚（スロット）を保持でき、組み合わせによってコンボが生まれる。

入手方法：ショップ購入、イベント、ボス撃破時の特別報酬。

#### タイル一覧（案）

| タイル名 | 効果 | レアリティ |
|---------|------|----------|
| 春霞のとばり | 春テーマのカードを使うたび、次の春カードの attack +2（スタック・上限なし） | common |
| 小倉の紅葉 | 秋テーマを2枚連続で使うとターン終了時に敵に 15 追加ダメージ | common |
| 逢坂の関 | 手札の最初の1枚はコスト 0 | uncommon |
| 難波の葦 | 恋・哀テーマのカードを使うたび、プレイヤー HP +1 | uncommon |
| 月の鏡 | 毎ターン、手札で最も elegance の高いカードの attack +5 | uncommon |
| 大江山の霧 | 同一歌人のカードを同じターンに2枚以上使うとき attack × 1.5 | rare |
| 龍田川の錦 | 手札に3つ以上のテーマが揃っているとき全カード attack × 1.2 | rare |
| 吉野の雪 | 冬テーマのカードを使うたびに「雪」を1スタック。5スタックで全体ダメージ 50 を発動してリセット | rare |
| 須磨の月 | 歌人が詠み人フィールドにいないとき attack × 1.8（孤独の覚悟） | epic |
| 百鬼の宴の幕 | ターン中に5枚以上使うと、最後の1枚の attack × 3 | epic |
| 歌聖の筆 | 六歌仙のカードを使うたびに elegance と pathos が両方 +5（ランが終わるまで） | legendary |
| 定家の夢 | カードの usedCount が10以上のものを使うたびに attack × 2（詠み込んだ句の力） | legendary |

#### タイル同士のシナジー

複数のタイルが揃うと追加効果が発動する（Balatro のセット効果的な仕組み）。

| 組み合わせ | 追加効果 |
|-----------|--------|
| 春霞のとばり + 逢坂の関 | 春カードのコストが恒久的に -1 |
| 小倉の紅葉 + 吉野の雪 | 秋冬コンボ：どちらのスタックも同じカウンタを共有して発動が2倍速 |
| 大江山の霧 + 歌聖の筆 | 六歌仙同士を同ターンに使うと追加で 30 固定ダメージ |
| 須磨の月 + 百鬼の宴の幕 | 5枚目以降のカードが全て attack × 4 |

---

### 2.7 御霊アイテム（Enhancement付与アイテム）

ランの途中で入手する消耗品。カード1枚に使うとEnhancementを付与して消える。

| アイテム名 | 付与するEnhancement | 入手方法 |
|-----------|-------------------|--------|
| 金泥の筆 | 金泥 | ショップ、休憩所 |
| 朱の墨 | 朱 | ショップ |
| 墨流しの硯 | 墨流し | ランダムイベント |
| 薄紙の巻物 | 薄紙 | ショップ |
| 蘇芳の染料 | 蘇芳 | elite 撃破 |
| 焦げ文字の護符 | 焦げ | ランダムイベント（ピンチ） |
| 宿り木の葉 | 宿り木 | 休憩所 |

封符アイテム（Seal付与）も同様に独立して存在する。

## 3. 全体の流れイメージ

```
ラン開始
  └─ スタートデッキ（例：旅テーマ3枚）
  └─ 歌枕タイル：「逢坂の関」（先読み：最初の1枚0コスト）

バトル1（因幡ステージ）
  └─ 旅テーマが地縁シナジー → コスト -1
  └─ No.16「立ち別れ」が usedCount 3 に達し Lv1 に成長
  └─ ショップで「薄紙の巻物」を購入、No.16 に付与 → コストが -1 さらに下がる

バトル3（吉野ステージ）
  └─ イベントで「吉野の雪」タイルを獲得
  └─ 「小倉の紅葉」タイルと組み合わせて秋冬コンボ始動
  └─ No.31 坂上是則（冬テーマ）に「月封印」付与

バトル5（ボス）
  └─ No.16 が usedCount 12 で Lv3「◎詠み込んだ句」
  └─ 「定家の夢」タイルで attack × 2
  └─ 薄紙 + 地縁シナジー + タイルスタック で爆発的ダメージ
```

  | 'haru' | 'koi' | 'tsuki' | 'tabi' | 'ai' | 'oni';

interface UtamakuraTile {

## 5. 未決事項

- 詠み上げレベル（usedCount）はランをまたいで保持するか、それともラン限りのリセットか
  - 保持案：愛用の一首への愛着が生まれる。セーブデータが複雑になる
  - リセット案：Balatro に近い「ラン内での盛り上がり」体験

- 歌枕タイルのスロット初期値（4か5か）と、スロット拡張方法

- 筆の跡と封印は**ラン終了後も保持するか**（保持するとランをまたいでカードが変容していく長期育成に）

- 御霊アイテムをデッキとは別の「アイテムポーチ」で持ち歩くか、手札に入れるか

- 地名ステージの地図表現：現在のノードマップをそのまま使うか、地図風UIに変えるか
